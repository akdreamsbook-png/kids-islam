# 🌙 موقع تعليم الأطفال الإسلام

موقع تفاعلي للأطفال مستوحى من كتاب «تعليم الأطفال الإسلام» (الطبعة الرابعة).
يعمل بدون إنترنت — فقط افتح `index.html`.

## الأقسام
- الإيمان والاعتقاد 🕌
- الآداب 🤲
- السلوك 😊
- العبادات 🕋
- التفسير 📖
- التحدي الكبير 🎮

## النشر على GitHub Pages
الموقع جاهز للنشر مباشرة (ملف `index.html` في الجذر).
بعد الرفع: Settings → Pages → Deploy from branch → `main` / `/ (root)`.
